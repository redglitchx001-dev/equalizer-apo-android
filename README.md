## 📌 Why Equalizer APO for Android?

The original [Equalizer APO](https://github.com/mirror/equalizerapo) for Windows relies on the Windows Audio Processing Object (APO) architecture (`IAudioProcessingObject` COM plugins for `audioengine.dll`). Because Android uses ALSA, AudioFlinger, and Android's `AudioEffect` framework, Windows APO DLL binaries cannot run natively on Android.

**Equalizer APO Android** bridges this gap by bringing the **entire DSP filter math engine**, **parametric EQ calculations (Biquad IIR filters)**, and **syntax parser** directly to Android. You can now import your PC Equalizer APO `config.txt` files, AutoEQ profiles, or Peace GUI presets right onto your phone!

---

## ✨ Key Features

- 📄 **Equalizer APO `config.txt` Syntax Parser**: Full support for importing and parsing standard Equalizer APO files (`Preamp: -3.0 dB`, `Filter 1: ON PK Fc 105 Hz Gain 4.5 dB Q 1.41`, `GraphicEQ:`).
- 🔊 **System-Wide Audio Equalization**: Background Foreground Service applies audio effects globally across Spotify, YouTube, Apple Music, Tidal, Poweramp, and local media players.
- 📈 **Real-Time Frequency Response Visualizer**: Dynamic magnitude response curve plotting combined filter gains from 20 Hz to 20,000 Hz.
- 🎛️ **Parametric Biquad Filter Engine**: Accurate implementation of Robert Bristow-Johnson's Audio EQ Cookbook formulas:
  - **PK** (Peaking EQ)
  - **LS** / **HS** (Low Shelf & High Shelf)
  - **LP** / **HP** (Low Pass & High Pass)
  - **NO** (Notch Filter)
- 🎧 **AutoEQ & Peace GUI Compatible**: Easily load headphone correction curves generated by AutoEQ.app.
- 💾 **Export & Sync**: Tweak settings on mobile and export back to `config.txt` for use on your PC.

## 🚀 How to Build the APK

### Automated GitHub Build
The repository contains a GitHub Actions workflow `.github/workflows/build-apk.yml` that automatically builds the APK on every commit! You can download the latest `app-debug.apk` directly from the [GitHub Actions tab](https://github.com/redglitchx001-dev/equalizer-apo-android/actions).

### Command Line Build (Local)

1. **Clone the repository**:
   ```bash
   git clone https://github.com/redglitchx001-dev/equalizer-apo-android.git
   cd equalizer-apo-android
   ```

2. **Build Debug APK**:
   ```bash
   ./gradlew assembleDebug
   ```
   *The generated APK will be located at:*  
   `app/build/outputs/apk/debug/app-debug.apk`

## 📖 Usage Instructions

1. **Install APK** on your Android device.
2. Grant **Audio / Media Playback** permissions when prompted.
3. Open the app and toggle **Master EQ Enable**.
4. Tap **Import .txt** to load your Equalizer APO configuration file exported from Peace GUI or AutoEQ.
5. Enjoy system-wide parametric equalization!
